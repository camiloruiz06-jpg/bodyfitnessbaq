CARPETA DEL LOGO
================

Guarda aquí el logo oficial del gimnasio con el nombre EXACTO:

    logo.png

(quedando: public/brand/logo.png)

Mientras el archivo no exista, la página muestra automáticamente un
logo de texto con el mismo estilo (badge rojo "GIMNASIO" + "Body
Fitness" en letra script). Apenas guardes el archivo, la página lo
usará sola — no hay que cambiar código.

Recomendación: PNG con fondo transparente.
